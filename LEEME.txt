CREW ARCHIVES — estructura del proyecto

crew-archives/
  index.html           <- toda la página (React + Tailwind por CDN)
  package.json         <- solo para:  npm run dev  (abre http://localhost:5173)
  media/
    crew-foto.jpg      <- foto del crew (portada del video destacado)
    droppa/            droppa-1.mp4 + droppa-1.jpg ... droppa-6
    diego/             diego-1.mp4  + diego-1.jpg  ... diego-17

Agregar más clips a un skater (ej. diego-18):
  1. Pon media/diego/diego-18.mp4 y media/diego/diego-18.jpg (mismo nombre)
  2. En index.html, en SKATERS, a Diego agrégale al final de hlClips:
     ,'media/diego/diego-18.mp4'

Para subir a GitHub:  git add .   git commit -m "..."   git push
